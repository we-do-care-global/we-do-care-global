01 / The case pathway

Where judgement
stays human.

Software can organise evidence, structure a case and flag a signal. It cannot decide that a case is medically valid. That line is explicit throughout the system.

  1. Ingest

    Cases arrive from multiple sources and are normalised into a single structured record. Sources are preserved alongside the normalised form so a reviewer can always check the original.

  2. Structure

    Case data is organised against the ICH E2B(R3) structure, with the elements a submission requires separated from the elements a reviewer needs to see first.

  3. Signal detection

    PRR and ROR calculations surface disproportionate reporting so a reviewer can prioritise. A statistical flag is a prompt to look, not a finding.

    Flag ≠ conclusion

  4. Qualified human verification

    A qualified reviewer validates every consequential output: causality assessment, expectedness, seriousness and the narrative. The system records who decided and why.

    Qualified reviewer

  5. Package

    Verified cases are assembled into ICSR packages and periodic report drafts (PSUR, PBRER) with the review trail attached.
