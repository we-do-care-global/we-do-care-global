02 / Performance claims

How a claim has
to be made.

A reproducible benchmark needs more than a number. This is the full list, and this website does not assert measured latency, accuracy or throughput for the Next systems.

01Commit SHA

The exact revision the measurement was taken from.

02Dataset

The tasks, their provenance and how they were selected.

03Environment

Hardware, model version, latency conditions, dependencies.

04Sample count

How many runs, and what the failure distribution looks like.

05Metric definition

What counts as a success and what counts as an error.

06Run command

The exact invocation, so a third party can repeat it.

07Raw output

Unedited results, not a summary of them.
