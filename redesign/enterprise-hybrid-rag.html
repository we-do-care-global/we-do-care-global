01 / The fusion problem

Neither search
alone is enough.

Lexical search finds the exact identifier. Dense search finds the paraphrase. Running only one of them guarantees a class of misses.

  1. 01

    BM25 lexical retrieval

    Ranks documents by term frequency against inverse document frequency. Precise on identifiers, error codes and named entities.

    Exact terms
  2. 02

    Dense semantic retrieval

    Ranks documents by embedding proximity. Finds the rephrased question that shares no keywords with the source document.

    Paraphrase
  3. 03

    Reciprocal rank fusion

    Merges the two ranked lists by position rather than by score, so neither retriever's scale dominates the result.

    Rank fusion
  4. 04

    Context assembly

    Chunks are assembled into context with source attribution, so a downstream reviewer can see where each claim came from.

    Attributed
