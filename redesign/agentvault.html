AgentVault

Bring tool registration, secret management and bounded execution into a clearer control layer.

01 / Project focus

Who may call what,
with which secret.

AgentVault is the registry where a tool becomes usable: declared scope, a named role, a credential reference and an execution boundary.

Tool registry

Every callable tool is registered with its input schema, its required permissions and the systems allowed to reach it. Unregistered tools are not callable.

Secret management

Credentials are stored and rotated as references, never as values in code or prompts. A tool receives a scoped credential for the duration of one call.

Bounded execution

Execution limits — timeout, output size, retry count — are declared per tool, so a misbehaving tool fails inside a known envelope.

Audit trails

Each call records who invoked it, under which role, with which credential reference and what the tool returned.
