## What This Organization Does

- **Repository Lifecycle** — Every repo includes `README.md`, `LICENSE` (Apache-2.0), `.gitignore`, `pyproject.toml`, `Dockerfile`, `docker-compose.yml`, `citation.cff`, `.zenodo.json`, tests, and a `docs/` landing page.
- **Zenodo Archiving** — GitHub releases trigger `.github/workflows/zenodo.yml` → versioned DOI deposit that syncs to the researcher ORCID profile.
- **ORCID Integration** — `citation.cff` and `.zenodo.json` embed `https://orcid.org/0009-0009-8515-2727` for machine-readable attribution.
- **Pages** — Every repo hosts `/docs` on `main` via GitHub Pages (`we-do-care-global.github.io/<repo>/`).
