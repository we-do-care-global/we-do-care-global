## The Philanthropic Foundation: 33% Pledge

**We Do Care Global** is built on a fundamental principle established by its founder, Emir Perla:
> **33% of annual corporate revenue is permanently dedicated to providing financial and material assistance to vulnerable individuals worldwide.**

Regardless of geographic boundaries or social background, every person deprived of basic necessities has the right to support for a dignified life. This commitment to global philanthropy is the cornerstone of the organization's identity and drives its ethical engineering ethos.

### 1. FoundationCentar — One-Click Agent Factory OS (v1.0.0)
- **What it does:** Autonomous cloud AI operating platform. One-Click Agent Factory orchestrating multi-agent workflows with human-in-the-loop CEO governance, bounded economics, evidence-first verification, and unified identity.
- **Repository:** [`we-do-care-global/FoundationCentar`](https://github.com/we-do-care-global/FoundationCentar)
- **Zenodo DOI:** [10.5281/zenodo.23073888](https://doi.org/10.5281/zenodo.23073888) / [10.5281/zenodo.22945778](https://doi.org/10.5281/zenodo.22945778)
- **Stack:** Python · FastAPI · React · TypeScript · NVIDIA NIM · vLLM · AppDeploy

### 2. AgentGuard — Agent Security & Governance Control Plane (v0.1.1)
- **What it does:** Policy engine, tool-call proxy, append-only tamper-evident audit log, approval queue, and instantaneous kill switch for LLM-based autonomous agents.
- **Live Webapp:** [https://we-do-care-global.github.io/agentguard/](https://we-do-care-global.github.io/agentguard/)
- **Repository:** [`we-do-care-global/agentguard`](https://github.com/we-do-care-global/agentguard)
- **Zenodo DOI:** [10.5281/zenodo.22945778](https://doi.org/10.5281/zenodo.22945778)
- **Stack:** Python 3.11/3.12 · FastAPI · Pydantic v2 · SQLAlchemy 2.0 · PostgreSQL · Redis · OpenTelemetry

### 3. Enterprise Hybrid-RAG — Production RAG with NVIDIA NeMo (v0.1.1)
- **What it does:** Production Retrieval-Augmented Generation using NVIDIA NeMo retrieval, hybrid dense/lexical search, reciprocal rank fusion (RRF), cross-encoder reranking, and continuous evaluation layer.
- **Live Webapp:** [https://we-do-care-global.github.io/enterprise-hybrid-rag/](https://we-do-care-global.github.io/enterprise-hybrid-rag/)
- **Repository:** [`we-do-care-global/enterprise-hybrid-rag`](https://github.com/we-do-care-global/enterprise-hybrid-rag)
- **Zenodo DOI:** [10.5281/zenodo.22945802](https://doi.org/10.5281/zenodo.22945802)
- **Stack:** Python · FastAPI · NVIDIA NeMo · NVIDIA NIM · Qdrant · BM25 · OpenTelemetry

### 4. Agent Eval — Evaluation & Observability Platform (v0.1.1)
- **What it does:** Comprehensive agent evaluation, telemetry, latency tracking, tool execution metrics, and continuous benchmark verification for autonomous workflows.
- **Live Webapp:** [https://we-do-care-global.github.io/agent-eval/](https://we-do-care-global.github.io/agent-eval/)
- **Repository:** [`we-do-care-global/agent-eval`](https://github.com/we-do-care-global/agent-eval)
- **Zenodo DOI:** [10.5281/zenodo.22945804](https://doi.org/10.5281/zenodo.22945804)
- **Stack:** Python · FastAPI · TypeScript · React · Vite · OpenTelemetry

### 5. AgentVault — Enterprise Control Plane for AI Tools (v0.1.3)
- **What it does:** Enterprise control plane for AI tools — policy governance, zero-trust secrets lifecycle, multi-provider function calling, and per-tool granular telemetry. Enact and Model Context Protocol (MCP) compatible, self-hosted, and fail-closed.
- **Live Webapp:** [https://we-do-care-global.github.io/agentvault/](https://we-do-care-global.github.io/agentvault/)
- **Repository:** [`we-do-care-global/agentvault`](https://github.com/we-do-care-global/agentvault)
- **Zenodo DOI:** [10.5281/zenodo.22983557](https://doi.org/10.5281/zenodo.22983557)
- **Stack:** TypeScript · Node.js · Enact · MCP · Vite · TailwindCSS

### 6. Pharma Intelligence OS — Pharmacovigilance & Regulatory Workspace (v0.1.1)
- **What it does:** Pharmacovigilance & regulatory intelligence workspace: ICSR case review with human verification, ICH E2B(R3) package generation, disproportionality signal management (PRR/ROR), PSUR/PBRER working drafts, and real-time FDA tracking via openFDA.
- **Live Webapp:** [https://we-do-care-global.github.io/pharma-intelligence-os/](https://we-do-care-global.github.io/pharma-intelligence-os/)
- **Repository:** [`we-do-care-global/pharma-intelligence-os`](https://github.com/we-do-care-global/pharma-intelligence-os)
- **Zenodo DOI:** [10.5281/zenodo.22983388](https://doi.org/10.5281/zenodo.22983388)
- **Stack:** TypeScript · React · Vite · TailwindCSS · Lucide Icons · openFDA API · GitHub Pages
