## About

We Do Care Global is a research-grade engineering organization focused on **autonomous agent governance**, **production RAG pipelines**, and **research-data management (RDM)**.

Every repository ships with:
- `README.md`, `LICENSE` (Apache-2.0), `.gitignore`
- `citation.cff` + `.zenodo.json` (machine-readable scholarly attribution)
- `.github/workflows/zenodo.yml` (automated Zenodo deposition on release)
- `docs/index.html` (self-contained landing page, GitHub Pages `/docs`)
- `Dockerfile` + `docker-compose.yml` (local development)
- Minimal installable Python package + tests
